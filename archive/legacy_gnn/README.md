# Legacy learned-model pipeline

The scripts and reports here document the superseded Siamese/triplet GNN,
branched modality experiments, production reference banks, and ensemble
inference. They are preserved because their audits motivated the final
pharmacophore approach.

These scripts retain their original imports and paths. For exact replay, check
out the corresponding historical commit or restore the large artifacts listed
in `../README.md`. They are not supported entry points in the sealed project.
